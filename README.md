# The Lonely Marsh

This repository contains the official website for **The Lonely Marsh**, an original puppet performance written and directed by Julia Blair. 

## About the Project
Inspired by Aldo Leopold's essay *Marshland Elegy* and the inland wetland ecosystems of Wisconsin, *The Lonely Marsh* is a live puppet show featuring an original musical score. The performance aims to educate and engage audiences—specifically children and families—on the importance of wetland conservation and the return of Whooping Cranes to the landscape.
